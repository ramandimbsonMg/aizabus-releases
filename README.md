<h1 align="center">AizaBus</h1>

<p align="center">Où suis-je sur la ligne, et où dois-je descendre ?<br>
L'aide aux usagers des taxi-be d'Antananarivo : le téléphone donne la position, l'application annonce l'arrêt courant et le prochain arrêt.</p>

## Télécharger

| Système | Fichier |
|---|---|
| **Android** (arm64) | [AizaBus.apk](https://github.com/ramandimbsonMg/aizabus-releases/releases/latest/download/AizaBus.apk) |

Sur le téléphone : ouvrir le fichier, autoriser l'installation depuis cette source si Android le demande, puis installer.
L'application est disponible en français, en malgache et en anglais.

## Versions

Toutes les versions sont dans l'onglet [Releases](https://github.com/ramandimbsonMg/aizabus-releases/releases). Chaque APK est signé avec la même clé : une nouvelle version s'installe par-dessus la précédente.
